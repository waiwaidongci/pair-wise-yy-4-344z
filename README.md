# 水下考古潜水记录

直接打开 `index.html` 使用。页顶页签切换两个页面，数据存浏览器 localStorage：

- **沉船标记**：点击平面图添加标记，筛选、编辑、删除、时间线和导出 JSON。
- **气量放行台**：潜后登记气瓶读数，自动判定耗气与水面休息是否达标，安全员复核后放行下一潜。

## 业务文件拆分

| 文件 | 职责 |
| --- | --- |
| `gas-rules.js` | 耗气规则（纯计算）：用气量、SAC、近三次中位数与两成判定、深度休息门槛 |
| `review-log.js` | 复核记录（数据层）：潜次登记、安全员意见、更正后旧读数与旧意见留档 |
| `station.js` | 页面操作：放行台渲染、潜后登记/复核/更正表单与计划重排 |

## 放行规则

- 队员潜后登记：瓶容、起止压力、最大深度、底部时间、出水时刻。
- 用气量 =（起始压力 − 出水压力）× 瓶容；耗气率 SAC = 用气量 ÷（底部时间 × (1 + 深度/10)），折算水面升/分钟。
- 以本人最近三次（本潜之前）SAC 中位数为基准，本潜 SAC **高出基准两成**（严格 >120%）转待复核；不足三潜时显示"暂无基准"，不判耗气异常。
- 水面休息门槛随**上一潜最大深度**：≤12m 30 分 / ≤18m 45 分 / ≤24m 60 分 / ≤30m 90 分 / 更深 120 分；与上一潜的水面间隔不足即转待复核。
- 出水压力低于 50 bar 仅作复核余量提醒，不单独拦截。

## 复核与更正

- 待复核潜次由安全员在右侧补录**复核余量**并填写意见，可"补录余量并放行"或"维持待复核"。
- 仅每人最新一潜可在页面更正读数；更正后旧读数及当时的复核意见**整份留档**（旧放行作废），该潜回到待复核，下一潜计划即时重排。
- 首次打开会写入四名队员的演示数据；清浏览器站点数据可重置。
