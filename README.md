# 水下考古潜水记录

直接打开 `index.html` 使用。

- `index.html` — 标记页：点击沉船平面图添加标记，支持筛选、编辑、删除、时间线和导出 JSON。
- `gas.html` — 气瓶消耗与水面间隔放行台：气量核算、休息门槛、待复核与放行。

## 放行台业务文件划分

| 文件 | 职责 |
| --- | --- |
| `gas-rules.js` | 耗气规则（纯计算）：用气量、深度耗气率、SAC、本人最近三次中位数与两成判定、按深度的水面休息门槛 |
| `review-records.js` | 复核记录：潜后登记入库、安全员复核补录余量放行、读数更正后旧记录留档与计划重排（localStorage） |
| `gas-console.js` | 页面操作：放行板、登记表、记录列表、复核/更正弹窗与试算预览 |

## 作业流程

1. **潜后登记**：队员登记瓶容、起止压力、最大深度、底部时间、出水时刻，表单即时试算用气量与 SAC。
2. **自动判定**：SAC 高出本人最近三次潜次中位数两成，或出水后水面休息未达深度门槛（≤10m 30分 / ≤18m 60分 / ≤24m 90分 / ≤30m 120分 / 更深 180分），自动转**待复核**；无异常为**待放行**。不足三次基线不判耗气。
3. **安全员复核**：复核后补录余量，余量不低于 50bar 方可**放行下一潜**。
4. **更正重排**：上一潜读数可更正，旧读数快照留档；更正后该队员其后未放行潜次级联重判，已放行潜次标记“基线已变，下一潜前复算”。

数据存于浏览器 localStorage（键名 `zfl30GasLogs` / `zfl30GasArchives`），首次打开放行台会生成四名队员的演示数据。
